# Ожидаемые результаты автоматических проверок

Тесты выполняются через pytest с плагином `firebird-qa`.

## 1. Проверка исходной базы

Тест `database.structure.initialization` должен пройти успешно.

| Проверка | Ожидаемый результат |
|---|---:|
| CUSTOMERS | 3 записи |
| PRODUCTS | 4 записи |
| ORDERS | 3 записи |
| ORDER_ITEMS | 4 записи |
| Заказы без существующего покупателя | 0 |
| Позиции без существующего товара | 0 |
| Пользовательские индексы из сценария | 4 |

## 2. Проверка backup/restore

Тест `database.backup.restore` выполняет:

1. Создание резервной копии исходной тестовой БД командой `gbak -b`.
2. Проверку наличия и ненулевого размера файла `.fbk`.
3. Восстановление в отдельный файл БД командой `gbak -c`.
4. Подключение к восстановленной БД.
5. Повторную проверку количества записей, ссылочной целостности и индексов.

Тест считается успешным, если все проверки проходят без исключений.

## 3. Итог

Успешное выполнение теста подтверждает, что резервная копия создаётся, восстанавливается в отдельный файл, а восстановленная база содержит ожидаемые данные и индексы.

Проверка не подтверждает размещение таблиц и индексов в отдельных TABLESPACE. Для этого требуется согласовать версию Firebird и поддерживаемый ею синтаксис TABLESPACE с куратором.
